| Column Name | Required Data Type | Brief Description |
| :---------- | :----------------- | :---------------- |
| `name`      | `VARCHAR(100)`     | Instructor’s full name. |
| `role`      | `VARCHAR(30)`      | Instructor’s role for the course (e.g., Primary, TA). |
| `course_id` | `VARCHAR(20)`      | Unique course identifier (e.g., DS2002, CHEM4410). |
| `title`     | `VARCHAR(150)`     | Official title of the course. |
| `level`     | `INT`              | Course level number (e.g., 200, 400). |
